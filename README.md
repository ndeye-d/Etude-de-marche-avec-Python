# 📊Etude de marché avec Python
## 🎯Objectif
La **Poule qui Chante** est une société qui fait de l’élevage et la vente de poulet sous le label de **« Poulet Agriculture Biologique »**.
L’activité de cette société est basée en France, le PDG de cette entreprise aimerait se développer à l’international.  
Pour cet étude de marché je me suis basée sur les données ci-dessous qui proviennet du site de la [Food and Agriculture Organization of the United Nations (FAO)](https://www.fao.org/home/en/)
- Population
- PIB
- Disponibilité alimentaire
- Stock de poulet
- Importation de poulets
- Tendance dans l’élevage de poulets
- Emission de CO2 dû à l’élevage
- Stabilité politique

## 🛠️Outils
- Python
  - **Pandas** : Analyse et exploration des données
  - **Seaborn**, **Plotly** et **Matplotlib** : Visualisation des données
  - **Sklearn** : Analyse des Composantes Principales
  - **Scipy** : Dendrogramme
